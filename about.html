서비스 소개

큰돌은 바둑과 오목을 차근차근 익히는 연습장입니다

처음 배우는 사람이 단수, 활로, 포획, 5목 위협을 직접 눌러보며 이해하도록 만든 웹 트레이너입니다.

무엇을 돕나요?

큰돌은 바둑 입문자가 돌이 잡히는 원리를 배우고, 오목 입문자가 4목 차단과 열린 3목을 익히도록 돕습니다. 글만 읽는 서비스가 아니라 문제, 대국, 복기를 함께 제공합니다.

운영 원칙

  1. 초보자가 이해할 수 있는 말로 설명합니다.
  2. 광고는 학습판과 조작 버튼을 방해하지 않는 위치에만 둡니다.
  3. 개인정보를 최소한으로 다루고, 정적 페이지에서 기본 기능이 동작하게 유지합니다.
  4. 문제 오류, 착수 오류, 모바일 화면 문제를 운영 체크리스트로 계속 점검합니다.

운영자 정보

큰돌은 macacolabs GitHub 저장소에서 관리하는 개인 학습 프로젝트입니다. 서비스 변경, 콘텐츠 보강, 오류 수정 기록은 저장소 커밋과 이슈로 남깁니다.

운영 저장소: macacolabs/baduk-trainer

콘텐츠 검수 기준

새 학습 글은 제목, 설명, 관련 글 링크, 광고 위치, sitemap, RSS feed, 내부 링크 검사를 통과해야 공개합니다. 바둑과 오목 규칙 설명은 초보자가 이해할 수 있는 표현을 우선하고, 오류 제보가 들어오면 관련 글과 문제를 함께 수정합니다.

문의와 피드백

버그, 문제 오류, 추가했으면 하는 학습 주제가 있다면 GitHub 저장소 이슈로 남길 수 있습니다. 앱 안에서 이상한 판 위치, 클릭 오류, 설명 오류를 발견하면 화면 크기와 사용한 브라우저를 함께 적어주세요.
