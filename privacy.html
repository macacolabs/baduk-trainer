수집하는 정보

큰돌은 회원가입 없이 사용할 수 있는 정적 웹 앱입니다. 현재 서버로 이름, 이메일, 연락처 같은 직접 식별 정보를 전송하지 않습니다.

학습 진도, 오답, 설정 같은 앱 사용 기록은 사용자의 브라우저 localStorage에 저장됩니다. 이 정보는 사용자의 기기 안에 남고, 운영자 서버로 전송되지 않습니다.

localStorage 사용 목적

localStorage는 사용자가 푼 문제, 틀린 문제, 대국 설정, 학습 단계처럼 앱을 다시 열었을 때 이어서 연습하기 위한 정보에 사용됩니다. 이 기록은 로그인 계정과 연결되지 않으며, 다른 브라우저나 다른 기기로 자동 이동하지 않습니다.

광고와 쿠키

향후 Google AdSense 같은 광고가 적용되면 광고 제공자가 쿠키 또는 유사 기술을 사용할 수 있습니다. 광고가 적용되는 시점에는 이 방침과 화면 안내를 최신 상태로 갱신합니다.

승인 전에는 실제 광고 스크립트를 넣지 않습니다. 승인 후에는 광고 제공자가 광고 노출, 부정 클릭 방지, 맞춤 광고 또는 비맞춤 광고 제공을 위해 쿠키를 사용할 수 있습니다.

외부 서비스

사이트는 GitHub Pages로 배포됩니다. 사용자가 GitHub 이슈 링크를 눌러 문의를 남기면 GitHub의 계정과 정책이 적용됩니다. Google Search Console, AdSense 같은 외부 서비스는 사이트 운영과 검색/광고 관리를 위해 사용할 수 있습니다.

정보 삭제

브라우저 설정에서 사이트 데이터 또는 localStorage를 삭제하면 큰돌에 저장된 학습 기록이 삭제됩니다.

앱 안에서 저장된 학습 기록이 이상하게 보이면 브라우저의 사이트 데이터 삭제 후 다시 접속할 수 있습니다. 서버 계정이 없기 때문에 운영자가 사용자의 기기 안 localStorage를 직접 조회하거나 삭제할 수 없습니다.

어린이와 초보 학습자

큰돌은 바둑과 오목 학습을 돕는 일반 교육용 페이지입니다. 직접 식별 정보를 요구하지 않으며, 문의가 필요할 때는 보호자나 계정 소유자가 GitHub 이슈를 통해 남기는 방식을 권장합니다.

변경 고지

광고 적용, 분석 도구 추가, 저장 방식 변경처럼 개인정보 처리에 영향을 주는 변경이 생기면 이 페이지의 내용을 갱신합니다. 중요한 변경은 운영 체크리스트와 함께 확인합니다.

문의

서비스 운영, 개인정보, 광고 정책 관련 문의는 GitHub 저장소 이슈를 통해 받을 수 있습니다.
