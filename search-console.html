Search Console 등록 순서

검색 유입과 AdSense 신청을 준비하려면 Google Search Console에서 사이트 소유권을 확인하고 sitemap을 제출해야 합니다.

1. 사이트 등록

  1. Google Search Console에 접속합니다.
  2. 속성 추가에서 URL 접두어를 선택합니다.
  3. 등록 URL에 `https://macacolabs.github.io/baduk-trainer/`를 입력합니다.
  4. HTML 태그 방식의 verification meta 태그를 받습니다.
  5. 받은 태그를 `index.html`의 `` 안에 넣고 배포합니다.

2. sitemap 제출

소유권 확인이 끝나면 sitemap 메뉴에서 아래 주소를 제출합니다.

https://macacolabs.github.io/baduk-trainer/sitemap.xml

3. 먼저 색인 요청할 페이지

  • 메인: `https://macacolabs.github.io/baduk-trainer/`
  • 학습 허브: `https://macacolabs.github.io/baduk-trainer/learn.html`
  • 바둑 입문: `https://macacolabs.github.io/baduk-trainer/baduk-beginner.html`
  • 단수 설명: `https://macacolabs.github.io/baduk-trainer/baduk-atari.html`
  • 오목 전략: `https://macacolabs.github.io/baduk-trainer/omok-strategy.html`

4. 등록 후 관리

  • 색인 생성 범위에서 제외된 페이지가 있는지 확인합니다.
  • 검색어가 생기면 해당 글의 첫 문단과 내부 링크를 보강합니다.
  • 새 학습 글을 추가하면 `sitemap.xml`과 학습 허브를 함께 갱신합니다.
  • AdSense 신청 전에는 주요 학습 글이 검색엔진에서 접근 가능한지 확인합니다.
