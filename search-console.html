Search Console 등록 순서

검색 유입과 AdSense 신청을 준비하려면 Google Search Console에서 사이트 소유권을 확인하고 sitemap을 제출해야 합니다.

먼저 복사할 값

Search Console에서는 도메인 속성이 아니라 URL 접두어 속성을 선택합니다. 아래 URL을 그대로 복사합니다.

  • 속성 유형: `URL 접두어`
  • 사이트 URL: `https://macacolabs.github.io/baduk-trainer/`
  • sitemap URL: `https://macacolabs.github.io/baduk-trainer/sitemap.xml`

1. 사이트 등록

  1. Google Search Console에 접속합니다.
  2. 속성 추가에서 URL 접두어를 선택합니다.
  3. 등록 URL에 `https://macacolabs.github.io/baduk-trainer/`를 입력합니다.
  4. 소유권 확인 방식에서 HTML 태그를 선택합니다.
  5. `` 전체 태그를 복사합니다.
  6. 받은 태그를 `SEARCH_CONSOLE_META` 값으로 넣고 `node scripts/apply-search-console-meta.cjs`를 실행합니다.
  7. 스크립트가 안내하는 `node scripts/preflight.cjs`, commit, push 명령을 실행합니다.
  8. Search Console에서 소유권 확인을 누른 뒤 체크리스트 기록 명령을 실행합니다.

HTML 태그를 받은 뒤 실행

아래 명령에서 `발급값` 부분을 Search Console에서 받은 태그 전체로 바꿉니다.

$env:SEARCH_CONSOLE_META='<meta name="google-site-verification" content="발급값">'

node scripts/apply-search-console-meta.cjs

node scripts/check-search-console-meta.cjs

node scripts/preflight.cjs

git add -A

git commit -m "Add Search Console verification"

git push origin main

node scripts/wait-live-deploy.cjs

node scripts/check-search-console-meta.cjs --live

완료 표시 명령

외부 작업을 마치면 로컬 체크리스트에 완료 기록을 남깁니다. 이 기록이 있어야 AdSense 신청 전 상태 점수가 올라갑니다.

node scripts/mark-external-task.cjs "Search Console" "URL 접두어 속성으로 사이트 등록" --note "Search Console URL 접두어 속성에 사이트 URL 등록"

node scripts/external-next-action.cjs

2. sitemap 제출

소유권 확인이 끝나면 sitemap 메뉴에서 아래 주소를 제출합니다.

https://macacolabs.github.io/baduk-trainer/sitemap.xml

3. 먼저 색인 요청할 페이지

최신 우선순위는 로컬에서 `node scripts/indexing-priority.cjs`를 실행해 확인합니다.

  • 메인: `https://macacolabs.github.io/baduk-trainer/`
  • 학습 허브: `https://macacolabs.github.io/baduk-trainer/learn.html`
  • FAQ: `https://macacolabs.github.io/baduk-trainer/faq.html`
  • 9줄 바둑: `https://macacolabs.github.io/baduk-trainer/baduk-9x9-beginner.html`
  • 19줄 시작: `https://macacolabs.github.io/baduk-trainer/baduk-19x19-start.html`
  • 패 규칙: `https://macacolabs.github.io/baduk-trainer/baduk-ko-rule.html`
  • 급수표: `https://macacolabs.github.io/baduk-trainer/baduk-rank-roadmap.html`
  • 초보 실수: `https://macacolabs.github.io/baduk-trainer/baduk-beginner-mistakes.html`

4. 등록 후 관리

  • 색인 생성 범위에서 제외된 페이지가 있는지 확인합니다.
  • 검색어가 생기면 해당 글의 첫 문단과 내부 링크를 보강합니다.
  • 새 학습 글을 추가하면 학습 허브에 연결하고 `node scripts/sync-sitemap.cjs --write`와 `node scripts/sync-feed.cjs --write`를 실행합니다.
  • AdSense 신청 전에는 주요 학습 글이 검색엔진에서 접근 가능한지 확인합니다.

5. 첫 7일 운영 루틴

등록 직후에는 수치를 크게 기대하기보다, Google이 사이트 구조를 정확히 읽는지 확인하는 것이 먼저입니다. 하루에 한 번만 아래 순서로 보면 충분합니다.

  1. sitemap 제출 상태가 성공인지 확인합니다.
  2. 상위 색인 요청 URL이 가져올 수 있음 상태인지 확인합니다.
  3. 검색어가 아직 없어도 `node scripts/indexing-priority.cjs`로 다음 색인 요청 대상을 유지합니다.
  4. 노출 검색어가 생기면 `CONTENT_PLAN.md`에 후보를 추가하거나 기존 글 첫 문단을 보강합니다.
  5. 7일 뒤 `node scripts/prepare-adsense-application.cjs --live`를 실행해 AdSense 신청 준비 상태를 다시 확인합니다.

6. 검색어가 아직 없을 때 할 일

Search Console 데이터가 쌓이기 전에는 `CONTENT_PLAN.md`의 후보 큐를 기준으로 글을 추가합니다. 후보가 비어 있으면 초보자가 자주 검색할 개념형 주제를 먼저 넣고, 등록 후 실제 검색어가 생기면 그 검색어를 우선합니다.

  1. `node scripts/content-queue.cjs`로 다음 후보가 있는지 확인합니다.
  2. 후보가 없으면 `CONTENT_PLAN.md`에 검색 의도와 관련 글 2개 이상을 추가합니다.
  3. 새 글을 만들면 `learn.html`, `scripts/site-content.cjs`, 관련 글 링크를 함께 갱신합니다.
  4. `node scripts/preflight.cjs`로 sitemap, feed, SEO, 링크를 한 번에 확인합니다.
  5. 배포 뒤 `node scripts/wait-live-deploy.cjs`로 live sitemap 반영을 확인합니다.
