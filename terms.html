서비스 목적

큰돌은 바둑과 오목을 배우고 연습하기 위한 학습용 웹 앱입니다. 앱의 AI와 진단 결과는 학습 보조용이며 공식 기력 인증이 아닙니다.

제공 기능

큰돌은 바둑 배우기, 오목 배우기, 2인 대국, 학습용 AI 대국, 복기와 용어 설명을 제공합니다. 기본 AI는 정적 페이지 안에서 동작하는 학습용 엔진이며, 전문 대국 분석이나 공식 기력 판정으로 사용해서는 안 됩니다.

사용자 책임

사용자는 서비스 이용 과정에서 비정상적인 자동 클릭, 광고 부정 클릭, 서비스 방해 행위를 하지 않아야 합니다.

광고가 적용된 뒤에는 사용자가 자신의 광고를 직접 클릭하거나, 클릭을 유도하거나, 자동화 도구로 광고 노출과 클릭을 만드는 행위를 해서는 안 됩니다.

광고와 외부 서비스

서비스 운영을 위해 광고 또는 분석 도구가 추가될 수 있습니다. 외부 서비스가 적용되면 관련 정책과 고지를 함께 제공합니다.

광고는 학습판과 조작 버튼을 방해하지 않는 위치에만 배치합니다. 사용자가 돌을 두거나 정답을 고르는 과정에서 실수로 광고를 누르게 만드는 배치는 운영 원칙상 사용하지 않습니다.

저장 데이터

학습 진행도와 설정은 사용자의 브라우저 localStorage에 저장될 수 있습니다. 브라우저 데이터 삭제, 시크릿 모드 사용, 기기 변경에 따라 기록이 사라질 수 있습니다.

콘텐츠와 오류

바둑과 오목 설명, 문제, AI 추천은 학습을 돕기 위한 자료입니다. 규칙 설명이나 문제에 오류가 있을 수 있으며, 발견한 오류는 GitHub 이슈로 제보할 수 있습니다. 운영자는 확인 가능한 오류를 우선순위에 따라 수정합니다.

변경

기능 추가, 광고 적용, 운영 방식 변경에 따라 약관이 바뀔 수 있습니다. 중요한 변경은 페이지에 반영합니다.

문의

서비스 오류, 콘텐츠 오류, 광고 위치 문제는 GitHub 저장소 이슈를 통해 문의할 수 있습니다.
